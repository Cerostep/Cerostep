# www.cerostep.com

**DevOps × AI Agents：学习、实践与经验分享。English and Chinese, with English as the default.**

这是一个记录技术学习与工程实践的双语博客，关注 DevOps 与 AI Agent 的交叉领域：如何构建、交付、运行和持续改进 AI 应用。内容来自持续学习、动手实践与经验总结，尽量把概念落实为清晰的设计思路、可复用的方法和真实的问题复盘。

## 关注主题

- **DevOps 与平台工程**：自动化、CI/CD、云原生、可观测性、可靠性及开发者体验。
- **AI Agent 工程**：检索与工具使用、Agent 编排、上下文管理、评估与安全护栏。
- **AI 应用交付与运维**：将 AI 能力融入现有系统，并持续衡量和改进质量、成本、延迟与可靠性。
- **学习与经验整理**：记录实践过程、技术取舍、常见问题和可复用的经验。

## English

**DevOps × AI Agents: learning, building, and sharing practical experience.**

Cerostep is a bilingual blog about learning and engineering at the intersection of DevOps and AI agents. It explores how to build, deliver, operate, and continuously improve AI-powered applications. Posts grow out of ongoing study, hands-on work, and lessons learned, with an emphasis on practical design, reusable approaches, and honest problem-solving notes.

### Topics

- **DevOps and platform engineering**: automation, CI/CD, cloud-native practices, observability, reliability, and developer experience.
- **AI agent engineering**: retrieval and tool use, agent orchestration, context management, evaluation, and safety guardrails.
- **Building and operating AI applications**: integrating AI into existing systems while improving quality, cost, latency, and reliability.
- **Learning in public**: documenting experiments, trade-offs, troubleshooting, and reusable lessons.

## 项目结构 / Project structure

- `index.md` — 博客首页 / Blog home
- `about.md` — 关于页面 / About page
- `_posts/` — Jekyll 博客文章 / Jekyll posts
- `zh/` — 中文首页与关于页面 / Chinese home and about pages
- `_config.yml` — Jekyll 与 Minima 配置 / Jekyll and Minima configuration
- `_includes/` — 自定义模板（包括 Mermaid 支持）/ Custom includes (including Mermaid support)

文章以 Markdown 编写，由 Jekyll 和 Minima 生成静态页面，并通过 GitHub Pages 发布。

Posts are written in Markdown and published as a static site with Jekyll, the Minima theme, and GitHub Pages.
