# 关于 Cerostep

Cerostep 是一个关注 DevOps 与 AI Agent 交叉领域的学习和工程实践博客，探索如何构建、交付、运行并持续改进 AI 应用。

文章结合持续学习、动手实验与实践经验，主要涉及：

- DevOps、平台工程、自动化与可观测性。
- AI Agent 工作流、检索、工具使用、编排与评估。
- 关注质量、成本、延迟和可靠性的 AI 应用运维。
- 技术取舍、实践实验、问题排查与可复用经验。

博客希望分享可验证、可落地的工程经验，而不只是使用更多模型或 Agent。
